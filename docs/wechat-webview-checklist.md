## 3. 域名待办

- [ ] 替换 `miniapp/miniprogram/config.js` 中的正式 HTTPS 域名。
- [ ] 正式 H5 域名启用 HTTPS。
- [ ] 正式 H5 域名完成备案或符合微信业务域名要求。
- [ ] 在微信小程序后台配置并校验业务域名。
- [ ] 在微信小程序后台配置 request 合法域名。
- [ ] 按真实能力配置 uploadFile / downloadFile 合法域名；如果当前没有上传 / 下载能力，需在提审材料中说明。
- [ ] Supabase Auth 回调地址包含正式 H5 域名。
- [ ] 合规页面部署到正式 HTTPS URL，并可从小程序内访问。

域名一致性检查：

- `miniapp/miniprogram/config.js` 的 `WEB_APP_URL`、生产 `NEXT_PUBLIC_APP_URL`、微信后台业务域名应使用同一个 HTTPS origin。
- 如果 API 与 H5 同源，request 合法域名填写同一个 origin；如果 API 独立部署，request 合法域名需要额外包含 API origin。
- 如果 Supabase 邮件登录使用 Magic Link，Supabase Auth 的 Site URL 和 Redirect URLs 必须包含正式 H5 origin，否则微信内登录后可能无法回跳。
- 小程序 `web-view` 入口已限制为只能打开 `WEB_APP_URL` 同源页面；如需进入子路径，传入 `/path` 或同源完整 URL。

## 4. H5 配合项

- [ ] 微信内打开时隐藏或弱化 PWA 安装提示
- [ ] 摄像头扫码在微信内提供授权说明、拒绝授权提示和关闭摄像头流程
- [ ] 条码扫描在微信内提供手动输入兜底；若后续切换 `wx.scanCode`，同步更新后台隐私接口
- [ ] 食物图片加载失败时有兜底展示，不阻断添加食物或条码查询；内置兜底图应从 H5 同源静态资源加载
- [ ] 身体对比照当前只用于本地预览；API / schema 的 URL 字段若开始接收真实数据，需先完成隐私、上传域名和删除流程验收
- [ ] CSV 导出在微信内验证兼容性，不兼容时给出明确提示
- [ ] 设置页或其他固定入口可访问用户协议、隐私政策、反馈和数据导出
- [ ] 登录失败、网络错误、第三方条码查询失败时有用户可理解提示
- [ ] H5 内所有外链、协议页和反馈入口均使用 HTTPS，且不会跳出到未备案或未配置业务域名的页面。
- [ ] H5 不依赖 PWA 安装、Service Worker 离线能力作为小程序内核心路径。
- [ ] 使用 `postMessage` 与小程序通信时只传递必要状态，不传递密码、token、完整健康记录等敏感内容。

`web-view` 注意事项：

- 小程序 `web-view` 只能打开后台校验通过的业务域名；开发者工具关闭 `urlCheck` 不能代表可提审。
- `web-view` 中的 cookie、Magic Link 回跳、文件下载、扫码和分享行为都必须用 iOS / Android 微信真机验证。
- 微信审核人员通常按测试账号和备注操作，测试账号应能在 3 分钟内看到首页、记录、统计和设置入口。
- 如果条码查询依赖浏览器 `BarcodeDetector`，需要提供手动输入条码路径，避免审核设备不支持时卡住；摄像头授权被拒绝时也应能回到手动输入。
