# CarbCycle Tracker 个人信息收集说明草案

> 状态：上线前草案。用于微信小程序隐私保护指引、App / Web 隐私政策和提审材料准备。正式提交前需按真实功能、后台配置和运营主体复核。

## 1. 收集原则

- 仅围绕账号登录、饮食记录、身体记录、运动记录、饮水记录、统计分析、数据同步、安全风控和客服反馈收集必要信息。
- 不主动收集身份证号、银行卡号、精确定位、通讯录、麦克风、摄像头录制内容等与当前功能无关的信息。
- 条码扫描如在 H5 中使用浏览器能力或未来在小程序中使用 `wx.scanCode`，应在触发功能时说明用途；摄像头仅用于本地识别包装条码，不上传、不保存视频流。
- 当前身体对比照只在浏览器本地预览，不上传、不保存；若后续变为 URL 或上传路径，需要新增图片信息、上传域名、访问权限、删除和保留期限说明。

| 餐食记录 | 餐次、食物、克重、日期、营养素 | 记录摄入、计算达成率、生成统计 | 添加食物、应用模板 | 核心功能必需 | 应用数据库 |

| 计划与统计 | 每日目标、实际摄入、周报、成就进度 | 展示计划、趋势和成就 | 使用过程中自动生成 | 核心功能必需 | 应用数据库 |
| 日志信息 | 请求时间、接口路径、错误信息、基础网络信息 | 故障排查、安全风控、稳定性监控 | 使用服务时 | 必需 | Vercel / 应用日志 |

## 3. 小程序隐私接口映射

正式提审时需在微信小程序后台按真实能力勾选隐私接口。当前 `web-view` 壳代码本身未直接调用敏感原生接口；H5 内可能使用浏览器能力或未来改造为小程序原生能力。

| 能力 | 当前状态 | 提审处理建议 |
| --- | --- | --- |
| `web-view` 打开 H5 | 代码已具备 | 配置业务域名并说明用于打开线上服务 |
| 摄像头扫码 | H5 已在用户点击“打开摄像头”后尝试调用 `getUserMedia` + `BarcodeDetector`，微信内兼容性待验证 | 在 H5 文案和隐私材料中说明摄像头仅用于本地识别条码；若改用 `wx.scanCode`，需在后台声明扫码用途 |
| 手动条码输入 | 代码已具备 | 作为摄像头、`BarcodeDetector` 或第三方查询失败时的兜底路径，真机待验 |
| 文件下载 / CSV 导出 | H5 浏览器本地生成 | 微信内需真机验证，不兼容时给出提示 |
| 图片选择 / 上传 | 身体对比照当前仅本地预览；API / schema 已预留对比照 URL 字段；食物图片当前主要为外链 URL | 当前不按上传能力提审；若后续保存 URL 或上传图片，需补充相册 / 上传用途和 `uploadFile` 域名 |
| 账号登录 | Supabase Auth 方案已接入代码路径 | 需配置正式回调域名并验证微信内登录 |
| 客服 / 反馈 | 文档待补，产品入口待确认 | 提审前补充联系方式和反馈入口 |

## 4. 微信后台隐私保护指引填报建议

以下为提审前可直接核对的字段口径，正式提交时需按产品实际上线版本逐项确认。

| 微信后台字段 / 场景 | 建议填写内容 | 对应产品功能 | 必要性说明 |
| --- | --- | --- | --- |
| 用户登录信息 | 邮箱、认证用户 ID、登录状态 | 登录、会话管理、多设备同步 | 不登录无法提供账号数据隔离和云端同步 |
| 用户资料 | 昵称或姓名、性别、年龄、身高、体重、体脂率、活动水平、目标、训练日安排 | 引导页、设置页、计划生成 | 用于计算 BMR / TDEE 和碳循环目标 |
| 饮食记录 | 餐次、食物名称、克重、热量、蛋白质、脂肪、碳水、膳食纤维、日期 | 添加食物、餐食记录、统计 | 核心记录功能必需 |
| 身体健康记录 | 体重、体脂率、腰围、备注、日期 | 身体记录、趋势、周报 | 用户主动填写，用于趋势统计 |
| 运动健身记录 | 运动名称、类型、时长、消耗热量、日期 | 运动记录、统计 | 用户主动填写，用于训练复盘 |
| 饮水记录 | 饮水目标、饮水量、分次记录、日期 | 首页饮水追踪、设置 | 用户主动填写，用于饮水目标追踪 |
| 条码信息 | 用户主动扫描或输入的条码数字 | 条码商品查询 | 仅触发查询时处理，可使用手动输入兜底 |
| 摄像头权限 | 摄像头实时画面 | 条码扫描 | 仅用户点击扫码时请求，用于本地识别包装条码，不上传、不保存视频流 |
| 食物图片 URL | 第三方商品图、Unsplash 兜底图、自定义图片 URL | 食物卡片展示 | 图片来自外部来源或用户填写 URL，正式版需展示来源口径 |
| 日志信息 | 请求时间、接口路径、错误信息、基础网络信息 | 故障排查、安全风控、稳定性监控 | 用于保障服务安全稳定 |

当前明确不收集或不调用：

- 身份证号、银行卡号、精确定位、通讯录、短信、通话记录。
- 麦克风录音、摄像头录制内容；摄像头实时画面仅用于主动扫码时的本地识别。
- 相册原图或图片上传；当前身体对比照只本地预览。若后续启用食物图片或身体对比照上传，需要补充相册 / 图片上传用途、上传域名、访问权限、删除方式和保留期限。
- 微信手机号快捷登录；若后续接入，需要补充手机号用途和授权撤回说明。

## 5. 用户权利处理清单

上线前需明确并补齐：

- 查看和修改个人资料入口：设置页已有基础入口，需真机验证。
- 导出个人数据：CSV 导出已有基础能力，需微信内兼容验证。
- 删除单条记录：餐食、身体、运动等删除能力需按实际页面验证。
- 注销账号 / 删除全部数据：需补产品入口或人工处理流程。
- 撤回授权：需说明撤回后登录、同步、扫码等功能的影响。
- 投诉反馈：需补真实邮箱、电话或客服入口。

建议上线前承诺的处理时限：

| 用户请求 | 建议处理方式 | 建议时限 |
| --- | --- | --- |
| 更正资料 | 用户在设置页自行修改，或通过客服人工处理 | 自助即时；人工 15 个工作日内 |
| 导出数据 | 设置页 CSV 导出；微信内不兼容时提供人工导出 | 自助即时；人工 15 个工作日内 |
| 删除单条记录 | 产品内删除入口 | 自助即时 |
| 注销账号 / 删除全部数据 | 设置页入口或客服申请，完成身份核验后处理 | 15 个工作日内 |
| 投诉反馈 | 邮箱、电话或客服入口 | 15 个工作日内答复 |
