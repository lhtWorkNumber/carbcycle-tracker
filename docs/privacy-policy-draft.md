## 1. 适用范围

本隐私政策适用于 CarbCycle Tracker Web / PWA 版本及微信小程序 `web-view` 壳版本提供的碳循环饮食记录、计划、身体记录、运动记录、饮水记录、周报、成就和数据导出服务。

如果你通过微信小程序访问，本服务仍主要由线上 H5 页面承载。微信平台、小程序基础能力和第三方服务可能同时按照其各自规则处理必要数据，详见 [第三方服务说明](./third-party-services.md)。

## 2. 我们收集的信息

为提供核心功能，我们可能收集或处理以下信息：

- 账号信息：邮箱地址、登录状态、认证用户 ID。
- 个人资料：昵称或姓名、性别、年龄、身高、体重、体脂率、活动水平、目标、训练日安排。
- 饮食记录：餐次、食物名称、食物分类、克重、热量、蛋白质、脂肪、碳水、膳食纤维、记录日期；食物图片可能来自第三方商品图片、内置同源静态图片或用户后续填写的图片 URL。
- 自定义食物：食物名称、分类、营养素和图片 URL。代码路径已新增用户归属字段和当前用户过滤；正式版承诺“仅当前账号可见”前，仍需完成数据库迁移、接口权限、前端展示和测试账号隔离验收。
- 身体记录：体重、体脂率、腰围、备注、记录日期。代码路径已预留身体对比照 URL 字段；当前前端仅在浏览器本地生成预览，不随身体记录上传或保存。
- 运动记录：运动名称、运动类型、运动时长、消耗热量、记录日期。
- 饮水记录：饮水目标、饮水量、分次饮水记录、记录日期。
- 计划与统计：每日目标、实际摄入、周报、达成率、成就进度。
- 设备与日志信息：访问时间、请求路径、接口错误、运行日志、基础网络信息。日志仅用于安全、稳定性和问题排查。
- 条码查询信息：当你使用条码查询时，我们会向 Open Food Facts 查询对应商品信息，查询字段包括你输入或扫描得到的条码。扫码仅在你主动点击后请求摄像头权限，用于在本地识别包装条码；我们不上传、不保存摄像头视频流。若扫码不可用，你可以手动输入条码。

详见 [个人信息收集说明](./personal-information-collection-list.md)。

## 3. 我们如何使用信息

我们使用上述信息用于：

- 创建和维护账号登录状态。
- 生成碳循环饮食计划、营养目标和统计结果。
- 保存和同步餐食、身体、运动、饮水、模板、周报和成就数据。
- 提供条码查询、食物库、自定义食物、内置同源静态图、第三方商品图或用户自填图片 URL 展示和 CSV 导出功能。
- 排查故障、保障接口安全、限制异常请求。
- 满足法律法规、平台审核和合规要求。

我们不会将你的健康、饮食或身体记录用于与本产品无关的广告定向。若后续增加广告、商业化推荐或第三方分析能力，应在正式接入前更新本政策并再次告知用户。

## 4. 信息存储与保护

生产环境计划使用 Supabase PostgreSQL 保存用户和业务数据，Web 应用计划部署在 Vercel。我们会通过 HTTPS、登录鉴权、用户级数据隔离、接口校验、限流和日志监控等方式保护数据。

微信小程序版本通过 `web-view` 打开正式 H5 域名。小程序壳仅保存必要的 H5 入口配置，不在小程序本地额外保存用户饮食、身体、运动或饮水记录。用户记录主要由 H5 服务端和数据库处理。

当前小程序壳不直接声明原生摄像头、相册、上传或下载权限。条码扫码由 `web-view` 中的 H5 页面在用户主动点击后调用浏览器摄像头能力；是否可用仍需 iOS / Android 微信真机验证。

当前身体对比照前端仅用于本地预览，不进入数据库或对象存储。虽然 API / schema 已预留 `before_photo_url`、`after_photo_url` 字段，若后续上线“对比照 URL / 上传路径”能力，仍应在发布前补充：图片来源、上传或托管服务、访问权限、删除方式、保留期限、上传域名和微信后台隐私保护指引。

仍需人工确认：

- 正式生产域名。
- 数据库所在区域。
- 备份周期和保留期限。
- 数据删除和导出处理时限。
- 运营主体内部的数据访问权限流程。

## 5. 信息共享、委托处理和第三方 SDK

为提供服务，我们可能使用 Supabase、Vercel、Open Food Facts、微信小程序平台以及后续确认的监控服务。内置食物兜底图和登录 / 引导视觉图已作为 H5 同源静态资源提供；第三方服务的用途、数据类型和处理方式见 [第三方服务说明](./third-party-services.md)。

除以下情况外，我们不会主动共享你的个人信息：

- 你主动发起或授权的操作。
- 为完成产品功能所必需的委托处理。
- 法律法规、司法机关、监管部门或平台审核要求。
- 为保护用户、公众、运营主体或平台的合法权益所必需。

## 6. 你的权利

你可以在产品内查看、修改或导出部分个人资料和记录数据。正式上线前仍需补齐以下入口或处理流程：

- 账号注销或删除数据申请入口。
- 个人信息副本导出说明。
- 更正个人信息的处理流程。
- 撤回授权后的功能影响说明。
- 投诉、反馈和人工处理时限。

上线前建议补齐并在正式版中明确：

| 权利 | 处理方式 | 建议时限 |
| --- | --- | --- |
| 访问和更正资料 | 设置页自助修改；无法自助时通过客服处理 | 自助即时；人工 15 个工作日内 |
| 导出个人数据 | CSV 导出；微信内不兼容时提供人工导出 | 自助即时；人工 15 个工作日内 |
| 删除单条记录 | 餐食、身体、运动等记录页删除入口 | 自助即时 |
| 注销账号 / 删除全部数据 | 设置页入口或客服申请，完成身份核验后处理 | 15 个工作日内 |
| 撤回授权 | 退出登录、停止使用相关功能，或通过系统设置撤回权限 | 撤回后相关功能可能不可用 |
| 投诉反馈 | 联系邮箱、电话或客服入口 | 15 个工作日内答复 |

## 7. 未成年人保护

本产品面向具备独立健康管理和饮食记录判断能力的用户。若实际运营面向未成年人，应在上线前补充监护人同意、未成年人信息保护和内容提示机制。
