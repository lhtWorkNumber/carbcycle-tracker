## 1. 协议范围

本协议适用于 CarbCycle Tracker Web / PWA 版本及微信小程序 `web-view` 壳版本。你注册、登录、访问或使用本产品，即表示你已阅读并同意本协议及 [隐私政策](./privacy-policy-draft.md)。

## 2. 产品服务

CarbCycle Tracker 提供碳循环饮食计划、餐食记录、身体记录、运动记录、饮水记录、营养统计、周报、成就、自定义食物、条码查询和 CSV 导出等功能。

本产品输出的营养目标、计划、统计和建议仅用于一般健康管理和记录参考，不构成医疗诊断、治疗建议、处方、营养治疗或专业健身指导。若你存在疾病、孕期、哺乳期、进食障碍、未成年人使用、专业竞技训练或其他特殊情况，应先咨询医生、注册营养师或专业人士。

## 4. 用户内容与数据

你在产品内填写的个人资料、饮食、身体、运动、饮水、自定义食物和备注等内容归你或相应权利人所有。为提供服务，你授权我们在必要范围内存储、处理、计算、展示、同步和导出相关数据。

自定义食物已有用户归属代码路径，用于按当前账号隔离展示；正式承诺“仅创建者可见”前，仍需完成数据库迁移、接口权限、前端展示和跨账号隔离验收。请不要在自定义食物名称、备注或图片 URL 中填写个人隐私、他人信息或无权使用的内容。

当前身体对比照仅用于浏览器本地预览，不随身体记录上传或保存；API / schema 虽已预留图片 URL 字段，但前端尚未传入 URL。若后续上线图片 URL 或上传路径，你应确保图片内容合法、来源合规，且不包含无关个人敏感信息；我们也需要在上线前补充上传、删除和保留期限规则。

你应确保上传或填写的信息不侵犯第三方权益，不包含违法、敏感或不适宜公开的内容。当前版本不建议填写身份证号、银行卡号、精确住址、病历、诊断证明等与碳循环饮食记录无关的信息。
