## 2. 域名与后台配置

- [ ] 正式 H5 域名：待补充，必须 HTTPS，示例 `https://app.example.com`。
- [ ] `miniapp/miniprogram/config.js` 的 `WEB_APP_URL` 已替换为正式 H5 入口，建议与 `NEXT_PUBLIC_APP_URL` 使用同一 origin。
- [ ] `miniapp/project.config.json` 的 `appid` 已替换为真实 AppID。
- [ ] 微信后台业务域名已配置并完成校验文件部署，域名必须与 `WEB_APP_URL` 的 origin 一致。
- [ ] 微信后台 request 合法域名已配置，至少包含 H5 调用的同源 API 域名；如生产 API 独立部署，需额外加入 API 域名。
- [ ] uploadFile 合法域名已按真实功能配置；若当前版本不提供食物图片或身体对比照上传能力，在审核备注中说明“当前小程序壳不调用 `wx.uploadFile`，身体对比照仅本地预览”。
- [ ] downloadFile 合法域名已按真实功能配置；若 CSV 导出由 H5 浏览器本地生成且不调用 `wx.downloadFile`，在审核备注中说明并真机验证。
- [ ] Supabase Auth Site URL / Redirect URLs 已加入正式 H5 域名，例如 `https://app.example.com/**` 或实际回调路径。
- [ ] Vercel 或其他部署平台已绑定正式域名，且 HTTP 自动跳转 HTTPS。
- [ ] 合规页面已部署到正式 HTTPS URL，并能在微信内打开。

后台域名填写模板：

| 后台项 | 建议填写 | 核验方式 |
| --- | --- | --- |
| 业务域名 | `WEB_APP_URL` 的 origin，例如 `https://app.example.com` | 微信后台校验文件可访问，开发者工具打开时不报业务域名错误 |
| request 合法域名 | H5 API origin；同源部署时同业务域名 | 登录、记录、统计接口在真机微信内成功 |
| uploadFile 合法域名 | 仅在使用上传能力时填写真实上传域名 | 触发上传流程；当前无原生上传则备注不涉及 |
| downloadFile 合法域名 | 仅在调用 `wx.downloadFile` 时填写 | 触发下载流程；当前 CSV 为 H5 本地生成则备注不涉及 |
| Supabase Auth 回调 | 正式 H5 URL 与登录回调路径 | 邮箱登录 / Magic Link 在微信内可回到 H5 |
